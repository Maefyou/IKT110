# Smart Auction Agent

Advanced EV-based auction agent with live dashboard.

## Quick Start

```bash
cd ..
./quick_start.sh
```

## Files

- `smart_agent_with_dashboard.py` - Main agent with Flask dashboard
- `templates/dashboard.html` - Dashboard UI
- `logs/` - Game history logs (JSONL format)
